## 🚀 Sobre mí
Senior Mobile Software Engineer con más de 8 años de experiencia en desarrollo de software, especializado en aplicaciones móviles para entornos empresariales y fintech.

Actualmente enfocado en el análisis técnico, diseño, desarrollo, evolución y mantenimiento de soluciones móviles Android e iOS, trabajando tanto con tecnologías modernas como con sistemas legacy.

- 📱 **Android:** Kotlin, Java, Jetpack Compose, XML, Coroutines y Flow.
- 🍎 **iOS:** Swift, UIKit y SwiftUI.
- 🔄 **Multiplataforma:** Experiencia con Flutter, React Native y Kotlin Multiplatform (KMP).
- 🏗️ **Arquitectura y buenas prácticas:** Clean Architecture, MVI, MVVM, arquitectura modular, SOLID y patrones de diseño.
- 🔌 **Integraciones:** APIs REST/SOAP, microservicios, autenticación segura, Firebase y servicios backend.
- 🧩 **Modernización:** Experiencia en mantenimiento y evolución de aplicaciones legacy, migraciones tecnológicas y resolución de incidencias en producción.
- ⚙️ **DevOps Mobile:** Git, CI/CD, generación de builds APK/IPA y preparación para ambientes QA y producción.
- 🏦 **Experiencia sectorial:** Desarrollo de soluciones móviles para entornos financieros, bancarios y empresariales.
- 👨‍🏫 **Docencia:** Instructor de desarrollo móvil con experiencia en React Native, TypeScript, arquitectura mobile y buenas prácticas de ingeniería de software.
